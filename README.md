# Metacritic AI Game Analyzer 🎮🤖

Сервис автоматического мониторинга и сбора игр с **Metacritic**, суммаризации отзывов критиков и пользователей с помощью **Gemini 2.5 Flash Lite**, подбора похожих игр на основе семантических эмбеддингов, анализа популярных летсплеев на **YouTube**, а также интерактивного веб-интерфейса с **real-time мониторингом воркера по WebSocket**.

Разработано в качестве выполнения тестового задания на позицию **AI Automation Engineer**.

---

## 📋 Реализованный функционал

### 1. Обязательная часть
* ⏱ **Ежечасный планировщик (Cron)**: 1 раз в час запускает сбор 20 новых игр, которые сегодня ещё не обрабатывались (`0 * * * *`).
* 🔄 **Умная суточная ротация по ТЗ**:
  * Каждый новый день отсчет начинается заново.
  * Первые 20 игр берутся из раздела *New Releases* (`https://www.metacritic.com/game/`).
  * При последующих запусках в течение дня парсер берет игры из раздела *SEE ALL* (`https://www.metacritic.com/browse/game/all/all-time/new/?page=N`), постранично инкрементируя указатель страницы.
* 📦 **Сбор полной информации об игре**:
  * Название игры;
  * Обложка высокого разрешения;
  * Мультиплатформенность: все платформы игры (PC, PS5, Xbox Series X, Switch и др.) с индивидуальными оценками **Metascore** и **Userscore**;
  * Разработчик и издатель;
  * Описание игры;
  * Ссылка на видео / трейлер (с плеером).
* 🧠 **AI-резюме отзывов (Gemini 2.5 Flash Lite)**:
  * Анализирует отзывы критиков и пользователей.
  * Раздельно формирует структурированное резюме на русском языке:
    * Что нравится критикам (плюсы) / Что не нравится критикам (минусы);
    * Что нравится игрокам (плюсы) / Что не нравится игрокам (жалобы/минусы).
* 🔗 **Подбор похожих игр на основе Векторных Эмбеддингов**:
  * Для каждой игры вычисляется семантический вектор через модель `gemini-embedding-001`.
  * При открытии карточки игры на лету вычисляется косинусное сходство (Cosine Similarity) со всеми остальными играми в базе SQLite.
  * Клик по похожей игре мгновенно открывает её карточку.

### 2. Дополнительная часть 1: YouTube Летсплеи
* 🎬 Автоматический поиск самого популярного летсплея / прохождения игры на YouTube.
* 📝 Извлечение транскрипта (субтитров) блогера без скачивания тяжелых видеофайлов.
* 🎙 **AI-заключение блогера**: нейросеть анализирует рассказ летсплейщика и формирует вердикт о геймплее, динамике и рекомендациях.
* 📺 Встроенный плеер YouTube прямо в карточке игры со ссылкой на оригинальный ролик, именем канала и счетчиком просмотров.

### 3. Дополнительная часть 2: Веб-мониторинг в реальном времени
* ⚡ **WebSocket Live Stream**: вывод текущего статуса воркера (`В ожидании` / `Работает` / `Ошибка`), счетчиков и прогресса (`14 / 20 игр`).
* 🖥 **Терминал живых логов**: логи парсера и AI транслируются в реальном времени прямо в браузер без необходимости обновлять страницу.
* 🚀 **Кнопка принудительного запуска сбора**: позволяет в 1 клик запустить процесс парсинга очередных 20 игр прямо из веб-интерфейса с защитой от одновременных запусков.

## 🛠 Стек технологий

* **Backend**: Node.js 24, TypeScript, Express 5, WebSockets (`ws`), `node-cron`, `undici`.
* **Database**: SQLite (`better-sqlite3` с включенным режимом WAL для высокой производительности).
* **Парсинг**: Puppeteer с `puppeteer-extra-plugin-stealth` (обход Cloudflare, блокировка тяжелых шрифтов/медиа для мгновенной загрузки).
* **AI & LLM**: Google Gemini 2.5 Flash Lite (`gemini-flash-lite-latest`), Gemini Embeddings (`gemini-embedding-001`), поддержка HTTP/HTTPS прокси через `PROXY_LIST` для работы из РФ.
* **Frontend**: React 19, Vite, TailwindCSS v4, Lucide Icons (темная тема, карточки со стеклянным эффектом, адаптивная верстка).
* **DevOps**: Docker, Docker Compose.

### Вариант 1. Локальный запуск (Node.js)

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd AIAutomationEngineer
   ```

2. Убедитесь в наличии файла `.env` в корне (ключ Gemini и параметры прокси):
   ```ini
   HEADLESS=true
   GEMINI_API_KEY=AIzaSyDUgWTCqJDKge_jSNotdEzqGTwejKYHwWY
   PROXY_LIST=45.145.57.233:11319:PG7pvX:8xqvbu,104.238.190.248:11024:baFwqZ:Sq51aK
   ```

3. Установите зависимости и соберите фронтенд:
   ```bash
   npm install
   npm run build:frontend
   ```

4. Запустите сервер:
   ```bash
   npm start
   ```

5. Откройте приложение в браузере:
   **[http://localhost:3001](http://localhost:3001)**

### Вариант 2. Запуск через Docker Compose (Рекомендуется)

Запуск одной командой без необходимости устанавливать локальный Chrome и Node.js:

```bash
docker compose up --build -d
```

Сервис будет доступен на **[http://localhost:3001](http://localhost:3001)**. База данных SQLite и логи монтируются в локальные папки `./data` и `./ai_chat_logs`.

Остановить контейнер:
```bash
docker compose down
```

## 💬 Логи переписки с нейросетью (JSONL)

Согласно требованиям тестового задания:
> *"В результат включить: Всю переписку с нейросетью, можно raw JSONL-файлами"*

Полные файлы диалога с нейросетью сохранены в директории:
* `ai_chat_logs/transcript.jsonl` — компактная версия истории работы;
* `ai_chat_logs/transcript_full.jsonl` — полная untruncated версия со всеми шагами и ответами модели.
