# Metacritic AI Game Analyzer 🎮🤖

Высоконадежный сервис автоматического мониторинга и сбора игр с **Metacritic**, раздельной суммаризации отзывов критиков и пользователей с помощью **Gemini 2.5 Flash Lite** (со Structured Outputs), семантического подбора похожих игр на основе векторных эмбеддингов, анализа популярных летсплеев на **YouTube**, а также интерактивного веб-интерфейса с **real-time мониторингом воркера по WebSocket** и **гибридной базой данных (Dual-Driver: PostgreSQL + SQLite WAL)**.

Разработано в качестве выполнения тестового задания на позицию **AI Automation Engineer**.

---

## 📋 Реализованный функционал

### 1. Обязательная часть
* ⏱ **Ежечасный планировщик (Cron)**: 1 раз в час запускает сбор 20 новых игр, которые сегодня ещё не обрабатывались (`0 * * * *`).
* 🔄 **Умная суточная ротация по ТЗ**:
  * Каждый новый день отсчет начинается заново.
  * Первые 20 игр берутся из раздела *New Releases* (`https://www.metacritic.com/game/`).
  * При последующих запусках в течение дня парсер берет игры из раздела *SEE ALL* (`https://www.metacritic.com/browse/game/all/all-time/new/?page=N`), постранично инкрементируя указатель страницы в цикле (до 10 страниц) с фильтрацией дублей до набора ровно 20 тайтлов.
* 📦 **Сбор полной информации об игре**:
  * Название игры;
  * Обложка высокого разрешения;
  * Мультиплатформенность: все платформы игры (PC, PS5, Xbox Series X, Switch и др.) с индивидуальными оценками **Metascore** и **Userscore**;
  * Разработчик и издатель;
  * Описание игры;
  * Ссылка на видео / трейлер (с интерактивным плеером).
* 🧠 **AI-резюме отзывов (Gemini 2.5 Flash Lite)**:
  * Анализирует реальные цитаты критиков и пользователей со страниц `/critic-reviews/` и `/user-reviews/`.
  * Использует **Gemini Structured Outputs (`responseSchema`)** — 100% гарантия строгого JSON без риска сбоев парсинга.
  * Раздельно формирует структурированное резюме на русском языке:
    * Что нравится критикам (плюсы) / Что не нравится критикам (минусы);
    * Что нравится игрокам (плюсы) / Что не нравится игрокам (жалобы/минусы).
  * **Честные статусы:** при отсутствии отзывов на Metacritic не выдумывает ложные похвалы и не тратит квоту токенов, а честно указывает статус отсутствия данных.
* 🔗 **Подбор похожих игр на основе Векторных Эмбеддингов**:
  * Для каждой игры вычисляется семантический вектор через модель `gemini-embedding-001`.
  * При открытии карточки игры на лету вычисляется косинусное сходство (Cosine Similarity) со всеми играми в базе.
  * Клик по похожей игре мгновенно переключает модальное окно на выбранный тайтл.

### 2. Дополнительная часть 1: YouTube Летсплеи
* 🎬 Автоматический поиск летсплеев на YouTube со **строгой сортировкой по количеству просмотров** (выбирается самый популярный ролик).
* 📝 Извлечение транскрипта (субтитров) блогера без скачивания тяжелых видеофайлов.
* 🎙 **AI-заключение блогера**: нейросеть анализирует рассказ летсплейщика и формирует вердикт о геймплее, динамике и рекомендациях.
* 📺 Встроенный плеер YouTube прямо в карточке игры со ссылкой на оригинальный ролик, именем канала и счетчиком просмотров.

### 3. Дополнительная часть 2: Веб-мониторинг в реальном времени и Freemium-авторизация
* ⚡ **WebSocket Live Stream**: вывод текущего статуса воркера (`В ожидании` / `Работает` / `Ошибка`), счетчиков и прогресса (`14 / 20 игр`).
* 🖥 **Терминал живых логов**: логи парсера и AI транслируются в реальном времени прямо в браузер по каналу `/ws` без polling.
* 🛡️ **Freemium-квота и авторизация администратора (Zero Friction UX):**
  * Для удобства проверки гостю доступно **3 бесплатных запуска воркера** без авторизации и ввода паролей.
  * В правом верхнем углу размещена кнопка авторизации: `🔑 Войти как Админ (3/3 демо-запуска)`.
  * Модальное окно авторизации содержит явную подсказку демо-ключа: `skytec-admin-2026`.
  * Авторизованный администратор получает **безлимитный доступ** ко всем операциям воркера.
  * При исчерпании демо-квоты сервер возвращает `403 Forbidden` (`QUOTA_EXCEEDED`), надежно защищая внешние API от ботов.

### 4. Production-Ready особенности
* 🐘 **Dual-Driver архитектура БД**:
  * При наличии `DATABASE_URL=postgresql://...` (например, в Docker Compose) сервис подключается к **PostgreSQL 16**.
  * Без переменной окружения сервис работает на автономном **SQLite WAL** (`better-sqlite3`).
* 🩺 **Healthcheck эндпоинт**: `GET /health` (проверка соединения с БД, аптайма, памяти для Docker/K8s).
* 🛑 **Graceful Shutdown**: чистая обработка `SIGTERM` и `SIGINT` (закрытие сервера, соединений БД, WebSockets и браузера Puppeteer).
* 🔄 **Resilient Transport**: экспоненциальный бэкофф с джиттером на ошибки 429/503 и ротация прокси через `PROXY_LIST`.

## 🛠 Стек технологий

* **Backend**: Node.js 24, TypeScript (strict), Express 5, WebSockets (`ws`), `node-cron`, `undici`, `pg`.
* **Database (Dual-Driver)**: 
  * **PostgreSQL 16** (через пул `pg.Pool` в Docker Compose);
  * **SQLite WAL** (`better-sqlite3` для zero-config локального запуска и тестов).
* **Парсинг**: Puppeteer с `puppeteer-extra-plugin-stealth` (обход Cloudflare, блокировка тяжелых шрифтов/медиа для мгновенной загрузки).
* **AI & LLM**: Google Gemini 2.5 Flash Lite (`gemini-flash-lite-latest`) со Structured Outputs (`responseSchema`), Gemini Embeddings (`gemini-embedding-001`), поддержка HTTP/HTTPS прокси через `PROXY_LIST` для работы из РФ.
* **Frontend**: React 19, Vite, TailwindCSS, Lucide Icons (темная стеклянная тема, доступность A11y: роли, клавиатурная навигация, Escape).
* **DevOps**: Docker, Docker Compose (multi-container: сервис приложения + PostgreSQL).

## 🚀 Быстрый запуск

### Вариант 1. Локальный запуск (Node.js + SQLite WAL — Zero Config)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/GoncharovMaksim/AIAutomationEngineer.git
   cd AIAutomationEngineer
   ```

2. Создайте файл `.env` на основе образца `.env.example`:
   ```bash
   cp .env.example .env
   ```
   Укажите ваш ключ Google Gemini API:
   ```ini
   HEADLESS=true
   GEMINI_API_KEY=your_gemini_api_key_here
   PORT=3001
   ADMIN_SECRET=skytec-admin-2026
   ```

3. Установите зависимости и соберите проект:
   ```bash
   npm install
   npm run build:all
   ```

4. Запустите сервер:
   ```bash
   npm start
   ```

5. Откройте приложение в браузере: **[http://localhost:3001](http://localhost:3001)**.
   * Healthcheck доступен по адресу: **[http://localhost:3001/health](http://localhost:3001/health)**.

---

### Вариант 2. Запуск через Docker Compose (PostgreSQL 16 + App)

Запуск полноценного production-окружения с контейнером PostgreSQL и монтированием томов:

```bash
docker compose up --build -d
```

Сервис будет доступен на **[http://localhost:3001](http://localhost:3001)**.  
База данных PostgreSQL и логи монтируются в тома `pgdata` и `./ai_chat_logs`.

Остановить контейнеры:
```bash
docker compose down
```

---

### 🧪 Запуск тестов (Unit & Integration Tests)

Запуск 23 тестов (проверка парсинга прокси, ротации по дням, косинусного сходства векторов, Dual-Driver БД, эндпоинтов `/health`, авторизации и квот):

```bash
npm test
```
*Все тесты выполняются моментально (~1 секунда) в памяти без необходимости запускать сторонние базы данных.*
